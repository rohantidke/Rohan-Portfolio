# Rohan Tidke - Developer Portfolio 🚀

A high-performance, dark-themed developer portfolio website built with **React**, **Vite**, **Tailwind CSS**, and **Glassmorphism**, modeled after [kaushikmaslekar.vercel.app](https://kaushikmaslekar.vercel.app/) and customized specifically for **Rohan Tidke's resume**.

---

## ✨ Highlights & Features

- 🟢 **Recruiter Fast-Track (1-Min Summary Modal)**: Quick executive candidate summary detailing CGPA (8.5), graduating year (2027), 7-layer fraud engine highlights, microservices expertise, and direct email action.
- 💻 **Interactive Developer Terminal (CLI)**: Floating interactive terminal modal accessible via `>_ CLI` or keyboard shortcut `~` with commands (`help`, `about`, `skills`, `projects`, `exp`, `edu`, `contact`, `clear`, `sudo hire`).
- 🔍 **Command Palette (`⌘K` / Search)**: Quick keyboard-search modal filtering sections, project highlights, and contact actions.
- ⚡ **Projects Showcase**: 
  1. **Credential Validator Platform** (Spring Boot 3, FastAPI, Solidity, React, 7-layer fraud detection engine, Merkle proofs & OCR).
  2. **Retrieval-Augmented Generation (RAG) Platform** (Python, LangChain, Vector DBs, document chunking & semantic retrieval).
- 💼 **Work Experience**: Java Developer Intern & Network Engineer Intern achievements at Shri Software Technologies.
- 🎓 **Education & Certifications**: B.E. Computer Engineering (CGPA 8.5), Diploma (88.46%), AWS Certified Cloud Practitioner (2025), Python & Java Certifications.
- 📱 **Fully Responsive**: Mobile drawer navigation & desktop sticky glassmorphic navbar.

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS, Custom Glassmorphism, CSS Glow Utilities
- **Typography**: Inter + Fira Code Monospace
- **Deployment Ready**: Standard Vercel / Netlify configuration

---

## 📦 Getting Started

### 1. Install Dependencies
```bash
cd rohan-tidke-portfolio
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
